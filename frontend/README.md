# Darukaa.Earth frontend

Vite + React + TypeScript. Login/register talk to the Spring Boot JWT APIs. Dashboard, `/analytics`, and site pages plot Chart.js series from those APIs.

Seeded analytics are **generated demo data**, not field measurements.

Setup, env vars, Docker, and the stack decision (Java/MySQL spatial, not Python/PostGIS): repository root [`README.md`](../README.md). Architecture: [`docs/architecture.md`](../docs/architecture.md).
